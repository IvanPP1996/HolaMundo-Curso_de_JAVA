## ¿Que es JAVA?
Lenguaje multiplataforma __orientado a objetos__ y es una plataforma de computación lanzado en el año 1995 pero lanzado al publico en el año 1996 esta vinculado en mas de 56 miles de millones de dispositivos.

**JVM**
<br>
Maquina virtual de Java que ofrece especificación de como debe correr el código.

**JRE**
<br>
Java runtime enviorenment es el encargado de instalar el JVM en nuestras maquinas, este ofrece bibliotecas y archivos de configuración el codigo de esta se debe correr para cada uno de sus sitemas operativos (Linux, Mac, Windows, Solaris, etc).

**JDK**
<br>
Java development kit o kit de desarrollo para Java este incluye el compilador y el JRE.

**Clases**
<br>
**Objetos (Instancia de clase)**

Ejemplo:
- Control de Ps5
<br>
Clase: El diseño principal de un control (siempre se escribe la primera letra en mayuscula ControlPlayStation)
<br>
Objeto: Los controles que se han hecho con base en ese control (siempre se escribe la primera letra en minuscula controlPlayStation):
<br>
    1. Propiedades (color, botones): Caracteristicas del objeto.
    1. Metodos (mover jostick, Prender control): Acciones de ese objeto.

## Variables

#### **Numeros:**

1. Numeros enteros
    - **int**   <- ( -2.000.000.000 - 2.000.000.000 )                   <- 4bytes
    - **byte**  <- ( -128 - 127 )                                       <- 1byte
    - **short** <- ( -32768 - 32767 )                                   <- 2bytes
    - **long**  <- ( -90.000.000.000.000.000 - 90.000.000.000.000.000 ) <- 8bytes

1. Numeros decimales
    - **float**
    - **double** <- Numeros mas grandes

#### **Booleanos:**

- **Boolean** <- True
- **Boolean** <- False

#### **Caracteres:**

- **char** <- Una sola letra ejm. 'b'
